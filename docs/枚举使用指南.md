# 枚举使用指南

`app/enums/base_enum.py` 中的 `BaseEnum` 是项目统一的业务状态枚举基类：`code` 用于存储/接口传输，`label` 用于展示，`extra`
承载补充数据或函数。

## 1. 定义枚举

成员写法为 `(code, label[, extra])`，`code` 同时作为枚举的 `value`：

```python
from enums.base_enum import BaseEnum


class UserStatus(BaseEnum):
    ACTIVE = (1, "正常", lambda x: x + 1)
    DISABLED = (2, "禁用", lambda x: x + 2)
    DELETED = (3, "删除", lambda x: x + 3)
```

`extra` 可省略，也可放任意数据：

```python
class OrderStatus(BaseEnum):
    PENDING = (0, "待支付")  # 无 extra
    PAID = (1, "已支付")


class ReviewStatus(BaseEnum):
    PENDING = (0, "待审核", {"a": 1})  # dict 型 extra
    APPROVED = (1, "审核通过", {"b": 2})
```

## 2. API 一览

设 `e` 为某个枚举成员：

| 写法                             | 说明                              | 示例                       |
|----------------------------------|-----------------------------------|----------------------------|
| `e.name`                         | 成员名                            | `'DISABLED'`               |
| `e.code`                         | 状态码                            | `2`                        |
| `e.label`                        | 状态描述                          | `'禁用'`                   |
| `e.extra`                        | 补充属性原始值                    | lambda 或 dict             |
| `e.call_extra(*args)`            | 函数型则调用，数据型原样返回      | `102` / `{'b': 2}`         |
| `e.value`                        | 等于 `code`                       | `2`                        |
| `UserStatus(2)`                  | 按 value（即 code）查找           | `<UserStatus.DISABLED: 2>` |
| `UserStatus.code_of(2)`          | 按 code 查找，找不到返回 `None`   | `<UserStatus.DISABLED: 2>` |
| `UserStatus["DISABLED"]`         | 按成员名查找，找不到抛 `KeyError` | `<UserStatus.DISABLED: 2>` |
| `UserStatus.name_of("DISABLED")` | 按成员名查找，找不到返回 `None`   | `<UserStatus.DISABLED: 2>` |
| `UserStatus.match_of(cb)`        | 条件查找，找不到返回 `None`       | 见下                       |
| `UserStatus.choices()`           | 下拉框数据 `[(code, label), ...]` | `[(1, '正常'), ...]`       |

条件查找：

```python
UserStatus.match_of(lambda item: item.label == "禁用")
# <UserStatus.DISABLED: 2>
```

## 3. 完整示例

### 3.1 `UserStatus`（extra 是函数）

```python
for e in UserStatus:
    print([e.name, e.code, e.label, e.call_extra(100)])
# ['ACTIVE', 1, '正常', 101]
# ['DISABLED', 2, '禁用', 102]
# ['DELETED', 3, '删除', 103]

UserStatus.code_of(2)  # <UserStatus.DISABLED: 2>
UserStatus.code_of(99)  # None
UserStatus(2)  # 按 value 查找
UserStatus["DISABLED"]  # 按成员名查找
UserStatus.name_of("DISABLED")  # 按成员名查找，返回 None 而非抛异常
UserStatus.match_of(lambda item: item.label == "禁用")

UserStatus.ACTIVE.call_extra(100)  # 101
{"status": UserStatus.ACTIVE.code}  # {'status': 1}，标准库 json 需取 code；pydantic 可直接序列化枚举
UserStatus.choices()  # [(1, '正常'), (2, '禁用'), (3, '删除')]

status = UserStatus.code_of(2)
if status is UserStatus.DISABLED:
    print("账号已禁用，不能登录")
```

### 3.2 `ReviewStatus`（extra 是 dict）

```python
for e in ReviewStatus:
    print([e.name, e.code, e.label, e.call_extra()])
# ['PENDING', 0, '待审核', {'a': 1}]
# ['APPROVED', 1, '审核通过', {'b': 2}]
# ['REJECTED', 2, '审核拒绝', {'c': 3}]

ReviewStatus.APPROVED.call_extra()["b"]  # 2
ReviewStatus.match_of(lambda item: item.call_extra().get("b") == 2)  # APPROVED

status = ReviewStatus.code_of(1)
if status is ReviewStatus.APPROVED:
    print(f"审核通过，附加信息: {status.call_extra()}")
```

### 3.3 `OrderStatus`（无 extra）

```python
for e in OrderStatus:
    print([e.name, e.code, e.label])
# ['PENDING', 0, '待支付']
# ...

OrderStatus.code_of(1)  # <OrderStatus.PAID: 1>
OrderStatus(1)  # 按 value（即 code）查找
OrderStatus.name_of("SHIPPED")  # <OrderStatus.SHIPPED: 2>
OrderStatus.PAID.call_extra()  # None，无需判空
OrderStatus.match_of(lambda item: item.code >= 3)  # COMPLETED
OrderStatus.choices()

status = OrderStatus.code_of(1)
if status is OrderStatus.PAID:
    print("可以发货")
```

## 4. 注意事项

- **code 必须唯一**：子类定义时 `__init_subclass__` 会校验，重复直接抛 `ValueError: XXX 存在重复 code: [1]`。
- **重复 code 会被 Enum 当别名**：`list(cls)` 会跳过别名，所以校验基于 `cls.__members__` 遍历。
- **有成员的枚举不能再被继承**：这是 Python `Enum` 的限制，子类化会抛 `TypeError: cannot extend`。
- **JSON 序列化**：枚举本身不是 `int` 子类，标准库 `json.dumps` 不认，需取 `.code` / `.value`；FastAPI / pydantic 会按 `value`（即 code）自动输出数字。
- **与 int 比较**：`UserStatus.ACTIVE == 1` 为 `False`，需要裸 int 时取 `.code`，不要依赖隐式比较。
- **pickle**：成员按 `code` 还原，`extra` 里的 lambda 不影响成员本身序列化；但若要把 `extra` 单独序列化，需自行处理。
- **`extra` 类型是 `Any`**：可以是函数、字典或任意数据，统一用 `call_extra()` 访问可避免 `getattr` 和可调用性警告。

## 5. 新增枚举模板

```python
from enums.base_enum import BaseEnum


class XxxStatus(BaseEnum):
    FOO = (0, "待处理")
    BAR = (1, "处理中")
    BAZ = (2, "已完成")


if __name__ == '__main__':
    print(XxxStatus.choices())
    print(XxxStatus.code_of(1))
```
